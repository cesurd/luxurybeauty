# Luxury Beauty by Sen — Website-Entwurf

Vorschau-Deployment eines Website-Entwurfs für das Kosmetikstudio
Luxury Beauty by Sen in Bonn-Auerberg.

**Live:** https://cesurd.github.io/luxurybeauty/
**Designvarianten:** https://cesurd.github.io/luxurybeauty/entwuerfe/

Alle Seiten sind auf `noindex, nofollow` gesetzt — der Entwurf soll nicht
indexiert werden und nicht mit der bestehenden Domain konkurrieren.

## Inhalt

| Pfad | Seite |
|---|---|
| `/` | Startseite |
| `/laser-haarentfernung-bonn/` | Dauerhafte Haarentfernung |
| `/gesichtsbehandlung-bonn/` | Gesichtsbehandlungen |
| `/koerperbehandlung-bonn/` | Körperbehandlungen |
| `/wimpernverlaengerung-bonn/` | Wimpernverlängerung |
| `/preise/` | Preisliste |
| `/kontakt/` | Kontakt & Anfahrt |
| `/impressum.html`, `/datenschutz.html` | Rechtsseiten |
| `/entwuerfe/` | Drei Designrichtungen zur Auswahl |

## Technik

Statisches HTML ohne Framework. Eine CSS-Datei, ein kleines JS-Modul für
Mobil-Navigation, Scroll-Einblendungen und die Zwei-Klick-Karte. Schriften
lokal eingebunden, keine Cookies, kein Tracking, kein externes CDN.
Schema.org als JSON-LD (BeautySalon, Service, OfferCatalog, FAQPage,
BreadcrumbList, Person).
